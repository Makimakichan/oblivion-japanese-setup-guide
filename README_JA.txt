Oblivion 日本語化チェック＆英語に戻すガイド 1.0.0
作者：Makimakichan999

Oblivionに残っている旧日本語化ファイルを調べ、
「ファイルの場所」「外す手順」「元に戻す手順」を日本語で案内するアプリです。

■ まず知っておいてください
このアプリは確認と説明だけを行います。ファイルを自動で削除・変更しません。
日本語化そのものを導入するアプリではありません。
今の日本語環境で問題なく遊べている方は、見つかっても消す必要はありません。
別の日本語化へ切り替えるときや、以前何を入れたか確認したいときに使えます。

■ 使い方
1. ゲームとMO2を終了します。
2. ZIPを好きな場所へ展開し、Oblivion_Japanese_Setup_Guide.exeをダブルクリックします。
   ゲームのDataフォルダーへ入れたり、MO2のMODとして登録したりする必要はありません。
3. 画面に出たフォルダーを確認します。違う場合は「参照…」で選び直します。
   ・Oblivionのフォルダー：Oblivion.exeがある場所
   ・MO2のフォルダー：ModOrganizer.iniがある場所
   ・ゲーム設定のフォルダー：通常は「ドキュメント → My Games → Oblivion」
   MO2を使っていない方は「MO2に入れたMODも調べる」のチェックを外してください。
   「オープニング・エンディング動画も調べる」は、チェックを入れた時点で動画を含む検査が始まります。
4. 「日本語化ファイルを調べる」を押すと、選んだ範囲をいつでも調べ直せます。ゲームとMO2の場所が見つかれば、自動で始まります。
5. 一覧から気になるファイルを選ぶと、下に説明が出ます。
   画面下の「次にすること」に、選んだ項目で必要な作業を表示します。
   ・「① 対応方法を読む」：選んだファイルへの対応と、必要な復元方法を表示します。
   ・「② ファイルの場所を開く」：エクスプローラーで対象ファイルを選択します。
   ・「詳しい検査結果を見る」：内容を照合した根拠などを表示します。
   どのボタンも、自動では削除・交換・復元を行いません。

■ 結果の読み方
行の背景色と「対応の目安」で、次に何をするか区別できます。
・緑「残す」：旧日本語化を外すためだけに削除しないものです。
・黄「交換・取り外し候補」：旧日本語化と一致。移行する場合にだけ手順を確認します。
・黄「判断を保留」：外してよいか判断できません。内容を確認するまで残します。
・薄い赤「再検査が必要」：読み取れなかった場所を確認して調べ直します。
・灰「保管・参考」：予備ファイル、資料、すでに無効にしたものなどです。
黄色は「今すぐ削除・交換する」という指示ではありません。

「古い日本語化と同じ」：登録済みの旧ファイルと中身が同じです。
「確認が必要」：名前や中身を確かめる必要があります。
「同じ名前・中身は別」：現在使っているUIなどの可能性があります。そのまま残してください。
「残してください」：ほかのMODも使う部品です。日本語化を外すためだけに削除しないでください。
「調べられませんでした」：その項目は未確認です。「問題なし」という意味ではありません。
「0件」でも、すべての旧日本語化を見つけられた保証にはなりません。

■ 実際に外すとき
今の環境で遊べているなら、作業は不要です。
切り替える場合は、先にセーブ・MOD・設定の控えを作り、移行先の説明も読んでください。
旧日本語化だけのMODなら、まずMO2でチェックを外します。
ほかのMODと混ざっている場合は、MOD全体を消さず、表示された対象だけを確認します。
MO2のファイル非表示・移動は、同じMODフォルダーを使う別プロファイルにも影響します。
プロファイルのコピーだけではMODファイルは複製されません。
日本語パッチ済みOblivion.exeを使う場合は、旧obja.dllだけを先に外さず、同じ販売元・版の英語EXEを用意します。
旧パッチを再実行して解除しようとしないでください。
翻訳ESPを外す場合は、依存パッチやBashed Patchに旧翻訳が残っていないか別途確認します。
手作業で外すファイルは、すぐに削除せずゲームとMO2の外へ移し、元の場所を控えてください。
販売元の修復は、後から追加した旧DLL・UIや、MO2の上書き・INI設定を片付ける代わりにはなりません。
販売元の「修復」では、選んだファイル以外も元に戻る場合があります。
変更後は再検査し、ゲームを起動して表示を確認します。最初は既存セーブに上書きしないでください。

■ このアプリの動作環境
・対象ゲーム：従来版 The Elder Scrolls IV: Oblivion（Remasteredは対象外）
・確認した環境：Windows 11 / .NET Framework 4.8
・日本語の画面と説明を備えた、単体のWindowsアプリです。
・MOJC本体、xOBSE、MenuQue、MO2は、アプリを起動するためには不要です。
・管理者として実行する必要はありません。
・ゲーム、MOD、設定、セーブ、レジストリへ書き込みません。検査結果のネット送信も行いません。
・Windows 10、Steam Deck / Protonでのアプリ動作は未確認です。

■ 販売元・フォルダー構成について
・Steam版：実際の環境で検査を確認しました。原本の照合基準は記録済みのSteam版です。
・別ドライブ・独自フォルダー：各「参照…」で手動指定できます。自動入力は一部の標準候補とゲーム登録情報に限られ、全ドライブ・全Steamライブラリを探索するものではありません。
・MO2の独自配置：ModOrganizer.iniのMOD・プロファイル・overwriteの保存先を読み取ります。未対応のパス表記や読めない場所は未確認と表示します。
・GOG版：元ファイルの用意方法を案内しますが、このアプリの実機動作・GOG版原本との一致は未検証です。
・Game Pass / Microsoft Store版：実機未検証です。Oblivion.exeのあるフォルダーを指定し、読み取れるファイルを調べる設計ですが、販売元固有の配置・アクセス制限・復元操作は確認していません。
  原本照合でSteam版と異なっても、旧日本語パッチとは断定しません。アクセスできない場所の所有権やアクセス権を無理に変更せず、販売元の管理アプリと公式案内を確認してください。
・販売元が異なる英語EXE・原本を流用しないでください。Game Pass版へSteam版の復元手順を適用する案内ではありません。

■ 詳しい検査範囲
・OBJP / OBJA / JPMOD関連の名前と、登録済みの旧ファイルの内容
・OBJP_CompleteUIStringsTranslator.dll、旧UI、旧フォント設定
・ゲーム本体、指定したMO2の有効・無効MOD、各プロファイル、overwrite
・既知のSteam版Oblivion.exeとの照合と、4GB対応設定の確認
・登録済みの本編・DLC英語原本との照合、BSAの更新日時
・「オープニング・エンディング動画も調べる」を選んだ場合はゲーム本体側のオープニング・エンディングの内容照合
内容の照合にはSHA-256を使い、ファイル名だけで旧版と断定しません。

■ 調べられないこと
ゲーム内で正常に動くか、実際にどのMODが優先されるか、セーブの中身は確認しません。
MO2内の動画・BSA内部や、overwrite内の原本と同名のESP/ESMは、原本照合の対象外です。
共通部品として残すxOBSEなどは名前で区別しており、その中身の正しさや改造の有無は確認しません。
未知の旧版、名前を変えたDLL、BSAの中の旧データ、あらゆるEXE改造を網羅するものではありません。
GOG版など、登録されていないEXEを旧日本語パッチと断定しません。
検査対象は指定した1つのゲームと、必要なら1つのMO2です。別の環境は選び直してください。
途中のフォルダーリンクはたどらず、未確認として表示します。
BSAの日時だけでは、昔の変更ツールを使ったかまでは分かりません。

■ OBJP_CompleteUIStringsTranslatorを外す場合
日誌の日付や召喚生物名などの表示に関わる補助ファイルです。
外すだけで移行先に同じ機能が追加されるわけではありません。
移行先の対応状況を確認し、切り替え後はゲーム内の表示も確認してください。
